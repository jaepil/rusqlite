# Managed fork verification

`provenance.py` requires the pinned upstream rusqlite 0.39.0 revision, byte-identical Rust wrapper APIs and plain SQLite sources, and exactly the removal of the bundled memory-management define from the original build script. SQLCipher 4.19.0 replaces its original 4.10.0 bundle. `sqlcipher.json` pins the official release commit, SQLite baseline, bindgen version, Rust/rustfmt toolchain, portable binding target and generated source hashes. `update_sqlcipher.py --source CHECKOUT --check` independently regenerates the amalgamation, headers, Rust bindings and license and compares every byte; CI checks out that exact official commit and installs the required formatter. Git attributes retain canonical LF source bytes on Windows; provenance checks compare the actual compiled and packaged bytes without newline normalization. The update command without `--check` writes only these generated files and their hashes. It does not clean Cargo outputs, modify the official checkout, update dependencies or search unrelated build directories for generated bindings.

`examples/uqa_build_options.rs` checks the compiled memory-management option, ordinary values and connection-local memory release on both backends. SQLCipher checks additionally require the exact SQLCipher/SQLite runtime versions, encryption, incorrect-key rejection and durable reopen. Linux, macOS and Windows run the existing library tests with UQA's blob, statement-cache, scalar-function and hook features. Emscripten executes compiled-option and value checks with unchanged plain bundled SQLite. Runtime observations establish correctness, not a throughput improvement.

`sqlcipher_native.py` compiles the complete old and new SQLCipher amalgamations with ASan/UBSan and C11/C++17 clients. Both old-source controls must report the incompatible callback through UBSan's function check; the updated source must pass with every function check enabled. An uninstrumented 4.10.0 reference binary and the instrumented 4.19.0 clients exchange encrypted fixtures in both directions, including new commits, rollback/savepoints, retained live WAL, incorrect keys, export and rekey. Cipher integrity checks inspect the physical file after rekey closes and checkpoints its WAL; logical reads are also checked before close. OpenSSL remains uninstrumented in this dependency-level test. UQA separately instruments the whole Rust/native library with the maintainer-approved OpenSSL-only function exception. Diagnostic logs and summaries stay under ignored `target/sqlcipher-verification` or CI artifacts.

Archive checks inspect both normalized package identities, original manifests, shipped native/Rust source bytes and licenses. CI owns archive creation and publication; no local package build, publication dry-run or registry upload is used. Implementation PRs remain drafts during local work; marking ready starts the completed batch once. Push `uqa-v0.39.2` only for reviewed merged source. Publication needs source reproduction, all native jobs and Emscripten, then verifies a fresh registry consumer. Upstream Rust MIT and SQLCipher BSD notices remain intact.
